## Sampling Rate

- **After every task commit:** Quick run command (parse validity — catches YAML/interpolation breaks immediately)
- **After every plan wave:** Full suite command (boot determinism — the phase's core criterion)
- **Before `/gsd:verify-work`:** Full suite must be green
- **Max feedback latency:** 60 seconds
