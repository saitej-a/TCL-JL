<task type="auto">
  <name>Task 3: Wait-time calculation engine (ANAL-03)</name>
  <files>apps/analytics/services.py, apps/analytics/tests/test_wait_time_calculations.py</files>
  <action>
    Implement wait-time benchmarking in `apps/analytics/services.py`:
    1. `calculate_wait_time_metrics(queryset=None) -> dict`:
       - For candidate profiles in `queryset` (default all profiles), find the elapsed days to `JOINING_LETTER`.
       - Priority order for start date (D1):
         a. `TimelineEvent` with `event_type=OFFER_LETTER`.
         b. If no `OFFER_LETTER` event, fallback to `TimelineEvent` with `event_type=INTERVIEW`.
         c. If still missing, check `CandidateProfile.offer_letter_date`.
         d. If still missing, check `CandidateProfile.interview_date`.
       - End date: `TimelineEvent` with `event_type=JOINING_LETTER`.
       - Calculate:
         - `average_days`: mean wait days (float rounded to 1 decimal).
         - `median_days`: median wait days (float rounded to 1 decimal).
         - `min_days`: integer minimum days.
         - `max_days`: integer maximum days.
         - `sample_size`: integer count of candidates with valid start and end dates.
       - If `sample_size < ANALYTICS_MIN_COHORT_SIZE`, wait-time metrics are suppressed:
         `{"data_source": DATA_SOURCE_LABEL, "suppressed": True, "message": SUPPRESSED_MESSAGE, "disclaimer": DISCLAIMER_TEXT}`.
    2. Write thorough tests in `apps/analytics/tests/test_wait_time_calculations.py`:
       - Offer Letter to Joining Letter calculation.
       - Fallback to Interview Date when Offer Letter is absent.
       - Fallback to CandidateProfile fields when TimelineEvent records are absent.
       - Suppression when fewer than 5 candidates have calculable wait-time transitions.
       - Handling candidates with negative or invalid intervals (exclude anomalies).
  </action>
  <verify>
    <automated>docker compose run --rm web sh -c "pip install -q -r requirements-dev.txt && python -m pytest apps/analytics/tests/test_wait_time_calculations.py -v"</automated>
    Expect: All wait-time calculation tests pass.
  </verify>
  <acceptance_criteria>
    - Wait-time logic accurately identifies start and end milestone dates.
    - Fallback hierarchy (Offer Event -> Interview Event -> Profile Offer -> Profile Interview) works seamlessly.
    - Mean, median, min, max, and sample size are computed accurately.
    - Cohorts with < 5 valid wait-time samples return suppressed payload.
  </acceptance_criteria>
  <done>Wait-time calculation service complete with fallback handling and statistical metric generation.</done>
