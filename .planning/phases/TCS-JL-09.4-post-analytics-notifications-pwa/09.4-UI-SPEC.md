## Per-Surface Contracts

### §7.8 Post Detail (`/community/posts/:id`, PublicShell)
Back link → post card (category badge `[CATEGORY_LABEL]`, "Posted {relative}" right-aligned, title, body paragraphs, author line `👤 {display_name} • {batch} • {stream} • {location}`) → §6.8 action row (reuse `UpvotePill` untouched; `💬 {N} Comments`; `Share`; `Report`) → composer → threaded comments. Inline reply form inserts beneath parent with autofocus (§7.8 rule 2). Anonymous visitors: composer replaced by sign-in prompt (write is verified-only; read is public). Locked posts: composer replaced by the amber banner above; existing comments still visible.

### §7.9 Analytics (`/analytics`, PublicShell — read-public)
Filter row → four KPI cards (`Total Candidates` / `Waiting for JL` / `Reported JL Recvd` / `Reported Joined`) → two-column band (stream breakdown list with share bars · status distribution stacked bar + legend) → wait-times section (D1: only from the new aggregate; rows render `Average {N} days (Range: {a} to {b} days)` when data exists, else the insufficient-data line) → suppression notice block. Any suppressed block renders the notice/insufficient-data copy — **never fabricated numbers** (mockup's `1,248 / 412 / 320 / 85` are placeholder fiction; real values come from 7.2 + the D1 aggregate).

### §7.10 Notification Center (`/notifications`, RequireAuth)
Header with live unread count → tabs → list rows (type glyph `💬 ▲ 📢 📍` in tinted badge, message, optional quoted snippet, relative time) → click row = `POST /{id}/read/` then navigate to target anchor (§7.10 behavior). Empty state per copy table. AppShell bell (new): badge = unread count, links here.

### §10.1 PWA shell (all routes)
Web manifest (name `TCS Joining Tracker`, short `JL Tracker`, theme #4F46E5 light / #0F172A dark, display `standalone`, portrait-primary, 192+512 maskable icons). SW: cache core shell/static assets + cached timeline; `push` event → notification display; `notificationclick` → deep-link open. Offline amber banner on `navigator.onLine === false` / SW offline event. Install promotion ONLY after either trigger (account created + ≥1 timeline milestone, or community visited on 2 distinct days — enforced via stored signal, §10.1); push primer modal precedes any native permission request. Icons: generate from existing brand mark; no external icon package.
