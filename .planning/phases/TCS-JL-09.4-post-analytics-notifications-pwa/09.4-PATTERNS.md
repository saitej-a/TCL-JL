## Code excerpts (binding conventions)

**Fetch-then-render + scripted tests** (`CommunityFeedPage.tsx:47-61`):
```tsx
export function CommunityFeedPage(): React.ReactElement {
  const [posts, setPosts] = useState<PostCardData[] | null>(null);
  const [failed, setFailed] = useState(false);
```
Tests script axios via `test/axiosTestHelper.ts::scriptAdapter(script: ScriptedCall[])` — every new page test uses it; never assume StrictMode (9.3 lesson).

**Backend seam to implement** (`apps/notifications/backends.py:42-64`): `PushBackend.send(tokens, title, body, data) -> SendResult(success_count, failure_count, failed_tokens, retryable_tokens)`. `WebPushBackend` maps HTTP 404/410 → `failed_tokens`, transport errors → `retryable_tokens`.

**Endpoint service pattern** (`apps/analytics/services.py:312-360`): validate filters → count + `check_privacy_suppression(total)` → per-group `values().annotate(n=Count("id"))` → `apply_row_floor` → `_with_metadata(...)`. `get_batch_breakdown` is the line-by-line template for the new status-distribution aggregation; register the route in `apps/analytics/urls.py` with the module's docstring discipline.

**Settings seam** (`config/settings/base.py:365-369`): `PUSH_BACKEND = os.environ.get("PUSH_BACKEND", "auto")` — add `webpush` to the resolution chain in `get_push_backend()` and `VAPID_*` env reads beside `FIREBASE_CREDENTIALS_PATH`. Never commit keys; `.env*` only.

**Token layer discipline** (`frontend/src/theme/tokens.ts`): all spacing/typography via `TYPOGRAPHY`/`SURFACES`/`BUTTON_HEIGHTS`; color via `@theme` brand scale in `src/index.css`. New components may not introduce raw hex or off-scale spacing.

**Barrel + route conventions** (`components/index.ts`, `routes/router.tsx`): every new component is exported from the barrel; routes mount inside `PublicShell` (post detail, analytics) or `RequireAuth` (notifications); the AppShell bell slots next to the existing topbar cluster.

## Anti-patterns observed to avoid

- Disabled-with-fake-reason stubs (9.3's `[removed]` tombstone inventiveness) — a deferred action is recorded, not faked.
- Rendering fabricated numbers where a payload says `suppressed` (dashboard's suppressed-card rule applies to analytics blocks).
- Copy drift from §7.8–§7.10 (the UI-SPEC copy table is the single source).
- `tsc --noEmit` as the only type gate — build with `tsc -b` semantics (9.3 lesson).
