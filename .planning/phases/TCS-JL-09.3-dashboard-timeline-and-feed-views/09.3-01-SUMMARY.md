## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Successful upvote visibly reverted to the stale list count**
- **Found during:** Design reconciliation (post-Task 8)
- **Issue:** PostCard ignored the server's vote_count from the list payload, so a *successful* vote snapped back to the pre-vote number once the optimistic overlay cleared — UI-03's failure mode, inverted.
- **Fix:** PostCard accepts and passes the server count; UpvotePill reconciles after success.
- **Verification:** UpvotePill/PostCard tests; live re-run showing `vote_count: 2` on independent read.

**2. [Rule 1 - Bug] Feed tests assumed StrictMode remounting absent from the test renderer**
- **Found during:** Task 9 gates (pre-existing red before reconciliation edits)
- **Issue:** Two tests scripted a StrictMode replay that jsdom never performs; they were red before any reconciliation edits.
- **Fix:** tests de-StrictMode'd; suite green at 130.

**3. [Rule 1 - Bug] `npm run build` failing on committed TimelinePage code**
- **Found during:** Task 9 gates
- **Issue:** null-narrowing bug in `TimelinePage.handleSubmit` caught by `tsc -b`, missed by `tsc --noEmit` — the build gate had never actually been run for 9.3.
- **Fix:** narrowed the null case; build gate now part of every verify (recorded as a 9.4 watch-out).

**Total deviations:** 3 auto-fixed (all Rule 1 bugs). **Impact:** none on scope; all three were defects the gates or reconciliation surfaced, fixed and tested.
