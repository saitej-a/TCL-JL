## Sampling Rate

- **After every task commit:** Run the quick command for the touched app (`apps/moderation` or `apps/community`) + `ruff check apps config` + `ruff format --check apps config`
- **After every plan wave:** Run the full suite command + `python manage.py makemigrations --check --dry-run`
- **Before `/gsd:verify-work`:** Full suite must be green (638 baseline + all new)
- **Max feedback latency:** ~150 seconds

| Threat | Mitigation | Verified by |
|--------|-----------|-------------|

| T-08.1-03: scam regex leakage to attackers | Block message names category, never `matched_pattern` | response-body assertion test |
| T-08.1-04: debounce-cache poisoning | Key binds author_id inside the hash; no user-controlled key material outside bounded model fields | debounce tests (per-author isolation) |
