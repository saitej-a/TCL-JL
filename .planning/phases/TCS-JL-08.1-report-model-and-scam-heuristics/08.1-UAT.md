## Tests

### 1. XOR target constraint enforced at the database level
expected: `Report` model enforces that a report targets exactly one post or one comment, never both and never neither. Proved by `apps/moderation/tests/test_models.py` where raw inserts (`bulk_create`) bypassing Python `clean()` trigger `IntegrityError` directly from the `report_exactly_one_target` CheckConstraint.
result: pass
source: user-attested

### 2. Double-enforced pending report deduplication
expected: A candidate cannot submit duplicate pending reports on the same target. Attempting a duplicate returns HTTP 400 with `error.code: duplicate_report`. Enforced in `services.create_report` query check and backed by race-safe database unique constraints (`unique_pending_report_per_post`, `unique_pending_report_per_comment`). Once resolved or dismissed, reporting can occur again.
result: pass
source: user-attested

### 3. Report submission endpoint and view-level rate limiting
expected: `POST /api/v1/reports/` requires authentication and accepts standardized violation reasons. The `reports` rate throttle (10/hr) is declared directly on `ReportListCreateView.throttle_scope`, avoiding DRF ScopedRateThrottle inertness. The 11th request within an hour yields HTTP 429.
result: pass
source: user-attested

### 4. Pre-publication scam heuristics intercept content on all write surfaces
expected: Content matching any of the 4 scam regexes (paid JL, Telegram/WhatsApp scam links, guaranteed joining, NextStep/Ultimatix credential requests) is hard-blocked with HTTP 400 `scam_pattern_detected`. The error message names the category ("possible fee solicitation or credential request") and never echoes the regex. Evaluated on post create, post edit (merged state), comment create, and comment edit.
result: pass
source: user-attested

### 5. 60-minute duplicate post debouncing in Redis
expected: Submitting identical titles or identical normalized body text within 60 minutes is rejected with HTTP 400 `duplicate_post`. Debounce isolates keys per author and applies only to post creation (comments and edits are not debounced).
result: pass
source: user-attested
